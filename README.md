
# Memory Vibe ✨

An emotional aesthetic web app that transforms personal memories into shareable vibe cards.

## Features
- AI-generated emotional interpretation
- Aesthetic vibe cards
- Animated reveal transitions
- Soft gradients + glassmorphism
- Share/shareable cards
- Music recommendation
- Mobile-first responsive UI

## Tech Stack
Frontend:
- React + Vite
- Tailwind CSS
- Framer Motion

Backend:
- Node.js
- Express
- OpenAI API

## Setup

### Frontend
```bash
cd frontend
npm install
npm run dev
```

### Backend
```bash
cd backend
npm install
```

Create `.env`

```env
OPENAI_API_KEY=your_key_here
```

Run:
```bash
npm run dev
```

Backend runs on:
http://localhost:5000
